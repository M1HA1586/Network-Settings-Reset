# 🕊️ Code of Conduct

### NSR is a friendly place for everyone, whatever your age, experience, language or computer.

</div>

---

## 💙 What we expect

| | |
|:--:|---|
| 🙂 | Be kind and patient, especially with beginners |
| 🗣️ | Talk about the code or the idea, never about the person |
| 🔍 | Give details when you ask for help, and say thanks when you get it |
| 🤝 | Accept that people see things differently |

## 🚫 What is not accepted

| | |
|:--:|---|
| 🤬 | Insults, harassment, threats or hate speech |
| 📢 | Spam, advertising, or links to unrelated or unsafe files |
| 🕵️ | Sharing other people's private information |
| ⏰ | Pressuring the maintainer for fast answers or features |

## 📍 Where it applies

Issues, pull requests, discussions and any other space connected to this repository.

## ⚖️ Enforcement

The maintainer can edit, hide or delete comments, close issues and block people who break these rules.

To report a problem, message **`mihaifbd`** on Discord or use **Report content** on GitHub. Reports are handled privately.
